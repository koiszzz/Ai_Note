<p data-vmark="db5e">IT之家 8 月 5 日消息，阿里云今日宣布上线 One Key MCP 服务。开发者可通过统一的阿里云百炼 API Key 调用所有生态伙伴 MCP 服务，<strong>兼容 Qoder、Codex、Claude Code、Cursor 等主流 Coding Agent</strong>，简化多 MCP 服务的接入、鉴权与计费管理流程。</p><p data-vmark="10b1">此前开发者接入不同 MCP 服务需分别申请凭证、配置鉴权并完成联调；服务数量增加后，接入和维护成本也随之上升。<strong>One Key MCP 将流程集中至阿里云百炼平台，提供五项核心能力：</strong></p><ul class=" list-paddingleft-2"><li><p data-vmark="2fe5">统一密钥：减少不同服务商的凭证申请与配置；</p></li><li><p data-vmark="1622">平台内无感开通：无需跳转多个服务商控制台；</p></li><li><p data-vmark="e7fb">统一计量与账单：便于企业查看用量与对账；</p></li><li><p data-vmark="8d44">多框架适配：支持 CLI 和公网服务地址调用；</p></li><li><p data-vmark="ad35">安全管控：全链路加密及 API Key 黑白名单 IP 访问限制。</p></li></ul><p data-vmark="97de" style="text-align: center;"><img src="https://img.ithome.com/newsuploadfiles/2026/8/8a548dd2-2cba-4c64-a487-71bdec9ddca3.jpg" w="1080" h="613" data-mpos="2,2" data-weibo="0" data-vmark="8ad3" class="no-alt-img"></p><p data-vmark="bed9">官方表示，One Key MCP 服务首批包含 14 家合作伙伴，覆盖六大领域：</p><ul class="medium-size list-paddingleft-2"><li><p data-vmark="97d7">电商供应链：1688 提供供应商匹配、智能选品和采购寻源</p></li><li><p data-vmark="9877">时空与环境数据：高德云图、青悦信息提供时空、交通及环境监测数据</p></li><li><p data-vmark="b85c">金融投资：东方财富、恒生聚源、今日投资、盈米基金-且慢 AI、龙柏数据覆盖金融信息与投资分析</p></li><li><p data-vmark="11c5">法律合规：得理科技、e 签宝支持法律检索与电子签约</p></li><li><p data-vmark="16f6">产业与企业数据：北京上奇数字科技提供产业及企业数据查询</p></li><li><p data-vmark="7b0f">物流与车辆：秀派科技、安那其科技、网尚科技覆盖物流轨迹与车辆数据</p></li></ul><p data-vmark="5a7d">IT之家附链接：</p><p data-vmark="c209"><a href="https://agent.console.aliyun.com/store/mcp"><span class="link-text-start-with-http">https://agent.console.aliyun.com/store/mcp</span></a></p>

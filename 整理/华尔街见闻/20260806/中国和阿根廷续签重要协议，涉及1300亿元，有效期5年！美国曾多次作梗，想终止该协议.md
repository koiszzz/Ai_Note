# 中国和阿根廷续签重要协议，涉及1300亿元，有效期5年！美国曾多次作梗，想终止该协议

## 摘要

- 中国人民银行与阿根廷中央银行近日续签双边本币互换协议，规模为1300亿元人民币/28万亿阿根廷比索，有效期五年，经双方同意可以展期。
- 美方曾多次对中阿本币互换协议发难，污蔑其为"勒索机制"并施压阿根廷终止协议；外交部发言人林剑回应称中方合作从不针对第三方，也不应受第三方干扰。
- 去年10月，美国财政部与阿根廷央行曾宣布签署200亿美元本币互换协议。

## 正文

<p data-pm-slice="0 0 []">记者8月6日从中国人民银行获悉，近日中国人民银行与阿根廷中央银行续签了双边本币互换协议，互换规模为1300亿元人民币/28万亿阿根廷比索，协议有效期五年，经双方同意可以展期。</p>

<p>中国人民银行表示，中阿双边本币互换协议再次续签，有助于进一步深化两国金融合作，促进双边经贸往来，维护金融市场稳定。</p>

<p><span data-pm-slice="0 0 []">自特朗普第二次上台以来，美国官员曾多次对中阿本币互换协议发难，试图施压阿根廷终止协议。美方曾污蔑<strong data-pm-slice="0 0 []">中国同阿根廷本币互换合作是中国对阿的"勒索机制"，呼吁阿方考虑终止。</strong></span></p>

<p data-pm-slice="0 0 []">对此，外交部发言人林剑曾回应称，中方一贯在平等互利基础上同阿根廷开展各领域务实合作。长期以来，中阿本币互换合作为阿方维护经济金融稳定发挥了重要作用，受到阿方欢迎和积极评价。中国同有关国家双边合作从不针对第三方，也不应受到第三方干扰。到底是谁在勒索胁迫、无事生非，公道自在人心。我们奉劝美方摆正心态，与其花时间挑拨离间，不如为拉美和加勒比国家发展多做点实实在在的事情。</p>

<p><span data-pm-slice="0 0 []">去年10月，美国财政部与阿根廷央行宣布签署200亿美元本币互换协议。</span></p>

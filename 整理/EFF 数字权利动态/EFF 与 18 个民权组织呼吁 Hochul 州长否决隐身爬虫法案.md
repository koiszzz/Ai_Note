# EFF 与 18 个民权组织呼吁 Hochul 州长否决隐身爬虫法案

> [!info] 来源信息

## 摘要

- EFF 加入由 18 个公民社会组织组成的团体，致信鼓励纽约州长 Kathy Hochul 否决参议院第 9934A 号法案（纽约隐身爬虫禁止法案）。
- 信件指出：尽管该立法被包装为保护本地新闻业的措施，它却损害自由表达，并通过实际上对开放 Web 的自动化访问去匿名化与刑事化，树立危险先例。
- 法案要求所有 Web 爬虫披露身份与明确目的，并授予媒体机构不受约束的权力获取司法传票以揭开未具名自动化 Web 流量的身份——无需任何不当行为或实际伤害的证明——威胁数字隐私、损害互联网的基础架构，最终压制它声称要保护的独立新闻业。
- EFF 此前已解释，所谓的"隐身爬虫"只是不披露用户身份的公共 Web 数据访问与收集工具，支撑调查报道、学术研究与网络安全等重要工作。

EFF 加入由 18 个公民社会组织组成的团体，致信鼓励纽约州长 Kathy Hochul 否决参议院第 9934A 号法案——纽约隐身爬虫禁止法案。信件指出：尽管被包装为保护本地新闻业的措施，这项立法损害自由表达，并通过有效地对开放 Web 的自动化访问去匿名化与刑事化，树立了危险先例。通过要求所有 Web 爬虫披露其身份与明确目的，并授予媒体机构不受约束的权力获取司法传票、在没有任何不当行为或实际伤害证明的情况下揭开未具名自动化 Web 流量的身份，该法案威胁数字隐私、损害互联网的基础架构，并最终压制它寻求保护的独立新闻业。正如我们此前解释的，所谓的"隐身爬虫"只是访问与收集公共 Web 数据而不披露用户身份的自动化工具，它们支撑调查性报道、学术研究、网络安全防护等重要工作。

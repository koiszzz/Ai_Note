# EFF 报告发现：移动广告软件鼓励位置数据分享

> [!info] 来源信息
> - 数据源：EFF 数字权利动态
> - 发布时间：2026-08-04
> - 原文链接：[打开原文](https://www.eff.org/press/releases/mobile-ad-software-encourages-location-data-sharing-eff-report-finds)
> - Vault 原文件：[[信息源/EFF 数字权利动态/Mobile Ad Software Encourages Location Data Sharing, EFF Report Finds|查看原始文件]]

## 摘要

- 开发者必须警惕背叛用户隐私的广告库。旧金山——电子前沿基金会（EFF）报告发现，广告公司为帮助开发者变现应用而提供的一些软件开发工具包（SDK）会自动把用户位置数据送入位置数据经纪商用来追踪人的系统。
- EFF 开始调查各广告 SDK 的位置分享实践，以更好地理解从移动应用到位置数据经纪商的管道；调查揭示了这类 SDK 如何促成并鼓励位置数据分享——在用户不知情或未获有意义同意的情况下——通过侵犯隐私的默认设置、金钱激励与不清晰的文档。
- "默认设置很重要，不仅对用户，对应用开发者也是如此。"

开发者必须警惕背叛用户隐私的广告库。旧金山——电子前沿基金会（EFF）报告发现，广告公司为帮助开发者变现应用而提供的一些软件开发工具包（SDK）会自动把用户位置数据送入位置数据经纪商用来追踪人的系统。EFF 开始调查各种广告 SDK 的位置分享实践，以更好地理解从移动应用到位置数据经纪商的管道。调查揭示了这类 SDK 如何促成并鼓励位置数据分享——在用户不知情或未获有意义同意的情况下——通过侵犯隐私的默认设置、金钱激励与不清晰的文档。"默认设置很重要，不仅对用户，对应用开发者也是如此。"

# 开发者注意：背叛用户位置隐私的广告库

> [!info] 来源信息
> - 数据源：EFF 数字权利动态
> - 发布时间：2026-08-04

## 摘要

- 跨移动平台，广告公司向开发者提供软件工具包（SDK），让应用变现变得容易；但这些 SDK 会自动把用户位置数据送入位置数据经纪商用来追踪人的广告系统。
- 许多开发者甚至可能不知道这种隐私侵犯，更不用说直接受影响的用户；当开发者让广告 SDK 收集位置数据时，用户面临的不只是令人毛骨悚然的广告。
- 来自广告业的位置信息已被用于 ICE 调查、全球间谍工具、曝光同性恋牧师、追踪工会组织者与追踪美国军人。
- 默认设置很重要，不仅对用户，对应用开发者也是如此：EFF 调查识别出多个广告 SDK，它们在嵌入已获位置权限的 Android 应用时，公开承认默认收集与分享用户位置。
- 本报告解释广告 SDK 如何通过侵犯隐私的默认设置、金钱激励与不清晰的文档促成并鼓励位置数据分享；内容包括：数据经纪商如何从广告系统收割位置信息、广告 SDK 如何泄露位置数据、EFF 识别出的默认分享位置数据的广告 SDK、InMobi 通过强调金钱激励鼓励保持位置分享开启、BidMachine 在 EFF 技术分析后更新先前不准确的开发者文档等。

## 正文

以下是文章内容全文翻译。

跨移动平台，广告公司向开发者提供软件开发工具包（SDK），让应用变现变得容易。但这些 SDK 会自动把用户位置数据送入位置数据经纪商用来追踪人的广告系统。许多开发者甚至可能不知道这种隐私侵犯，更不用说直接受影响的用户。当开发者让广告 SDK 收集位置数据时，用户面临的不只是令人毛骨悚然的广告。来自广告业的位置信息已被用于 ICE 调查、全球间谍工具、曝光同性恋牧师、追踪工会组织者与追踪美国军人。默认设置很重要，不仅对用户，对应用开发者也是如此。EFF 调查识别出多个广告 SDK，它们在嵌入已获位置权限的 Android 应用时，公开承认默认收集与分享用户位置。如果应用开发者不密切关注其广告工具的位置分享设置，他们可能无意中暴露用户的位置信息。本报告解释广告 SDK 如何通过侵犯隐私的默认设置、金钱激励与不清晰的文档促成并鼓励位置数据分享。内容包括：数据经纪商如何从广告系统收割位置信息；广告 SDK 如何泄露位置数据；EFF 识别出的默认分享位置数据的广告 SDK；InMobi 如何通过强调金钱激励鼓励保持位置分享开启；BidMachine 如何在 EFF 技术分析后更新先前不准确的开发者文档；以及观察到的精确位置数据收集。

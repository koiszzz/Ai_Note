# 「隐身爬虫」不是开放 Web 的威胁，针对它们的法案才是

## 摘要

- AI 之争出现新的"妖怪"：所谓的"隐身爬虫"；实际上它们远非邪恶——只是不披露用户身份的、访问与收集公开 Web 数据的自动化工具。
- 匿名爬取支撑许多造福公众的重要工作：调查性报道、学术研究、网络安全防护等。
- 许多出版商仍想揭开爬虫身份，并推动授予其新权力的立法；这些立法提案威胁开放 Web、用户隐私与有价值的研究，却不直接解决它们号称要解决的问题。
- 令人警惕的是，这些有害提案正在获得势头：纽约州立法机构已通过"纽约隐身爬虫保护法案"（NY Stealth Crawler Protection Act），正在州长 Hochul 案头；预期其他州乃至国会将出现类似法案。
- 匿名爬取值得保护：研究者、记者与监督组织用不具名自动化工具收集问责强大机构、保护公众所需信息；例如非营利新闻网站 The Markup 用匿名爬虫调查科技公司潜在反竞争行为。

## 正文

以下是文章内容全文翻译。

在 AI 之争中出现了新的"妖怪"：所谓的"隐身爬虫"。我们承认——"隐身爬虫"这个说法听起来相当邪恶。实际上，它们远非如此。"隐身爬虫"只是访问与收集公开 Web 数据、而不披露用户身份的自动化工具。这类私有爬虫支撑各种造福公众的重要工作，包括调查性报道、学术研究、网络安全防护等。匿名爬取支撑开放 Web 一些最有益公众的用途。许多出版商仍想揭开爬虫身份——并推动授予其新权力的立法。这些立法提案威胁开放 Web、用户隐私与有价值的研究，却不直接解决它们号称要解决的问题。令人警惕的是，这些有害提案正在获得势头。纽约州立法机构已通过此类法案"纽约隐身爬虫保护法案"（NY Stealth Crawler Protection Act），现正放在州长 Hochul 的案头。我们预期其他州乃至国会将出现类似法案。这对开放 Web——以及它提供的众多好处——是重大问题。匿名爬取值得保护：匿名爬取支撑开放 Web 一些最有益公众的用途。研究者、记者与其他监督组织使用不具名自动化工具收集问责强大机构、保护公众所需的信息。匿名爬取助力重要的调查性新闻。例如，非营利新闻网站 The Markup 使用匿名爬虫调查科技公司潜在的反竞争行为，如亚马逊倾向于优先排序自家品牌商品。

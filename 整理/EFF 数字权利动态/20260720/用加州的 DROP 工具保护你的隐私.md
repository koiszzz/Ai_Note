# 用加州的 DROP 工具保护你的隐私

## 摘要

- 你是加州居民吗？那我们有激动人心的消息：有一个专门为你设计的工具，让你能通过一个相对简单的步骤保护隐私。它叫 DROP 请求（即 Delete Request and Opt-out Platform，删除请求与退出平台）。
- 这一份文书让你告诉加州注册的每个数据经纪商：你希望他们从数据库中删除你的信息，并请求他们停止出售与分享你的信息。
- 提交请求的作用：在 DROP 上提交请求将向加州登记册中的所有数据经纪商发送删除与退出出售的请求；数据经纪商是收集、重新包装并出售个人信息的公司。
- 文章还介绍 DROP 的运作细节、如何提交请求以及需要注意的事项。

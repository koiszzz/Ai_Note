# 终端智能体足以胜任企业自动化

## 摘要

- 提出假设：仅配备终端和文件系统的编码智能体，通过直接与平台 API 交互，可以更有效地解决许多企业任务
- 在多样化的真实世界系统上评估这一假设
- 低层终端智能体以极低成本匹敌或超越更复杂的智能体架构
- 简单灵活的程序化接口结合强大的基础模型应成为企业自动化的骨干

## 正文

构建能够与数字平台交互、自主执行有意义的企业任务的智能体，正引起越来越多的关注。在已探索的方法中，有基于模型上下文协议（MCP）等抽象构建的工具增强智能体，以及通过图形界面操作的网页智能体。然而，考虑到这些复杂智能体系统的成本与运维开销，它们是否必要仍不明确。

我们认为，一个仅配备终端和文件系统的编码智能体，通过直接与平台 API 交互，可以更有效地解决许多企业任务。我们跨越多样化的真实世界系统对这一假设进行了评估，并表明这些低层终端智能体以极小的成本匹敌或超越更复杂的智能体架构。我们的研究结果表明，简单、灵活的程序化接口与强大的基础模型相结合，应当成为企业自动化的骨干。

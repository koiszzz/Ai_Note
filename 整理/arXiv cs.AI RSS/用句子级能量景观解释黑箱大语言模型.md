# 用句子级能量景观解释黑箱大语言模型

> [!info] 来源信息

> - 作者：Maryam Rezaee、Pooriya Safaei、Maryam Asgarinezhad 等

## 摘要

- 提出模型无关、事后、句子级的归因解释器：训练基于能量的模型（EBM）作为代理，捕获 LLM 在提示与响应之间的内部概念一致性；能量景观引导轻量解释器网络的训练。
- 解释器作为独立工具运行：训练后无需再向 LLM 发起 API 查询，即可量化提示句子对用户指定目标输出的影响。
- 通过跨多样输入全局训练局部解释器，框架捕获更广泛的生成模式并缓解实例特定偏差。
- 实验表明 EBM 能准确模拟目标 LLM，使解释器有效识别对生成特定目标输出最具影响的提示句子。

## 正文

论文编号：arXiv:2608.02879v1（更新类型：new）。以下为摘要全文翻译。

专有大语言模型（LLM）的广泛采用（严格通过封闭 API 访问）为负责任部署创造了关键挑战：根本缺乏可解释性。为应对这一挑战，我们提出一个模型无关、事后、在句子层面运作的归因解释器。我们的方法训练一个基于能量的模型（EBM）作为代理，捕获 LLM 在提示与响应之间的内部概念一致性。这个能量景观引导一个轻量解释器网络的训练。独特的是，我们的解释器作为独立工具运行：一旦训练完成，它就能量化提示句子对用户指定目标输出的影响，无需进一步向 LLM 发起 API 查询。通过跨多样输入全局训练局部解释器，我们的框架捕获更广泛的生成模式并缓解实例特定偏差。实验表明，我们的 EBM 能准确模拟目标 LLM，使解释器有效识别对生成特定目标输出最具影响的提示句子。

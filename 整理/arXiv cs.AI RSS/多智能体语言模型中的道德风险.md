## 摘要

- 引入对话道德风险博弈：受控文本博弈，为语言智能体操作化隐藏行动结构——每集智能体可保留即时局部奖励或支付查询成本揭示主要帮助其他智能体下游决策的隐藏安全事实。
- 评估九个开放权重模型与一个前沿 API 模型，把行为分解为查询使用、信息转移实现、局部奖励保留、不安全选择、格式有效性与团队成功：基础开放权重模型常见保留局部奖励而无团队成功，或查询而未传递改变最终决策的信息。
- GPT-5.6 Sol 在主设置中达到天花板行为；在 3,015 决策的激励隔离实验中，其经验查询阈值在九个查询成本上跟踪 Holmström 导出的私人份额边界，平均绝对误差 0.013。
- 用监督微调、RLOO、顺序 SFT+RLOO 与 GEPA 提示优化作为诊断更新机制：效果异质（SmolLM3-3B 与 OLMo-7B 显示最清晰的机制一致权重级改善，GEPA 有时改善团队成功却减少或消除昂贵查询）；优化可以转移聚合奖励而不恢复指定协作机制，推动按机制级行为而非仅团队成功报告的评估。

## 正文

论文编号：arXiv:2607.23982v3（更新类型：replace-cross）。以下为摘要全文翻译。

当社会价值高的努力成本高昂、弱可观测且主要惠及他人时，合作可能失败。借鉴 Holmström 的团队道德风险模型，我们引入对话道德风险博弈（Dialogue Moral Hazard Game），一个为语言智能体操作化这种隐藏行动结构的受控文本博弈。每集中，智能体可以保留即时局部奖励，或支付查询成本揭示主要帮助其他智能体下游决策的隐藏安全事实。我们评估九个开放权重语言模型与一个前沿 API 模型，把行为分解为查询使用、实现的信息转移、局部奖励保留、不安全选择、格式有效性与团队成功。基础开放权重模型常见保留局部奖励而无团队成功，或查询却不传递改变最终决策的信息。GPT-5.6 Sol 在主设置中达到天花板行为，自主扫描对查询成本与团队奖励强烈响应。在一个 3,015 决策的激励隔离实验（使用脚本化伙伴）中，其经验查询阈值在九个查询成本上跟踪 Holmström 导出的私人份额边界，平均绝对误差 0.013。随后我们在覆盖允许处使用监督微调、RLOO、顺序 SFT+RLOO 与 GEPA 提示优化作为诊断更新机制。其效果是异质的：SmolLM3-3B 与 OLMo-7B 显示最清晰的机制一致权重级改善，而 GEPA 有时改善团队成功却减少或消除昂贵的查询。因此，优化可以在不恢复指定协作机制的情况下转移聚合奖励，这推动了报告机制级行为（而非仅团队成功）的评估。

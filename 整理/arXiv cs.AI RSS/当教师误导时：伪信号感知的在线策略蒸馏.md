## 摘要

- 提出 SA-OPD（伪信号感知在线策略蒸馏）框架：基于输入接地性与优化影响识别并过滤误导性 token 级监督——引入轻量输入接地性代理，估计 token 级蒸馏信号是否真正依赖输入；随后只过滤同时表现出低输入接地性与极端蒸馏分歧的 token，移除高影响伪更新，实现细粒度 OPD 优化。
- 在线策略蒸馏（OPD）通过用密集 token 级教师信号监督学生采样轨迹迁移教师能力；近期选择性 OPD 方法通过优先选择自信、信息丰富或可学习的信号改善该过程；但这些假设忽视语言模型的基本失败模式：其 token 级判断可能由输入无关语言先验、格式惯例或刻板推理模板驱动，而非任务特定证据——把此类优化相关但弱输入接地的监督称为 OPD 中的伪信号，它们可能产生大梯度却贡献很少任务改进方向。
- LLM 与 VLM 设置的大量实验显示 SA-OPD 一致优于香草 OPD 与竞争性选择性方法——把输入接地性确立为 OPD 监督选择的关键维度，提供缓解伪更新的简单有效策略。

## 正文

论文编号：arXiv:2608.03632v1（更新类型：new）。以下为摘要全文翻译。

在线策略蒸馏（OPD）通过用密集的 token 级教师信号监督学生采样轨迹来迁移教师能力。近期的选择性 OPD 方法通过优先选择自信、信息丰富或可学习的信号改善这一过程。然而，这些假设忽视了一个语言模型的基本失败模式：它们的 token 级判断可能由输入无关的语言先验、格式惯例或刻板的推理模板驱动，而非任务特定的证据。我们把这类优化相关但弱输入接地的监督称为 OPD 中的伪信号（spurious signals）：它们可能产生大梯度，却贡献很少的任务改进方向。为缓解这一问题，我们提出 SA-OPD，一个伪信号感知的在线策略蒸馏（Spurious-Signal-Aware On-Policy Distillation）框架：基于输入接地性与优化影响识别并过滤误导性的 token 级监督。SA-OPD 引入一个轻量的输入接地性代理，估计 token 级蒸馏信号是否真正依赖输入。随后它只过滤同时表现出低输入接地性与极端蒸馏分歧的 token，从而移除高影响的伪更新，实现细粒度的 OPD 优化。在大语言模型（LLM）与视觉-语言模型（VLM）设置的大量实验表明，SA-OPD 一致优于香草 OPD 与竞争性的选择性方法。这些结果把输入接地性确立为 OPD 监督选择的关键维度，并提供一种简单有效的缓解伪更新策略。

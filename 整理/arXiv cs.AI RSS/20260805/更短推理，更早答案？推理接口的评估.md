## 摘要

- 在匹配推理视界下跨 198 道 GPQA Diamond 与 500 道 MMLU-Pro 问题评估同一问题的配对运行：测试为 Qwen3-14B 宣布 token 限制的数字/简洁提示，以及 gpt-oss-20b 与 -120b 的训练努力设置。
- Qwen 提示把推理轨迹缩短 12–17%，而匹配 token 限制下的准确率变化小且混合；简洁/早答指令在 512 token 处把 MMLU-Pro 准确率提升 3.8 个百分点（含两运行均未完成时的 +2.7 分）；gpt-oss 完成低与中努力推理的候选 logit 答案比匹配视界高努力答案准确 14.5–26.3 分。
- 512 token 优势大部分来自较低努力更早完成，未完成运行间的差异更小且混合；错误早期答案常把概率集中在所选选项，因此更早停止不统一改善概率质量。
- 紧期限可偏向较低努力或简洁指令，而让高努力完成可恢复更高最终准确率；评估应分别报告期限前正确完成、运行停止时所得答案、未完成运行间的差异与分配给正确答案的概率。

## 正文

论文编号：arXiv:2608.03401v1（更新类型：cross）。以下为摘要全文翻译。

大语言模型在回答前常常长篇推理，增加成本与延迟。提示与训练设置可以缩短这种推理，但更短的轨迹可能只显示模型更早停止。在此，我们在匹配推理视界下跨 198 道 GPQA Diamond 与 500 道 MMLU-Pro 问题评估同一问题的配对运行。我们测试为 Qwen3-14B 宣布 token 限制的数字/简洁提示，以及 gpt-oss-20b 与 -120b 的训练努力设置。Qwen 提示把推理轨迹缩短 12–17%，而匹配 token 限制下的准确率变化小且混合。简洁/早答指令在 512 token 处把 MMLU-Pro 准确率提升 3.8 个百分点，包括两运行均未完成时的 +2.7 分。其在 2,048 token 处的增益不确定。对 gpt-oss，完成低与中努力推理的候选 logit 答案比匹配视界的高努力答案准确 14.5–26.3 分。512 token 优势的大部分来自较低努力更早完成，而未完成运行间的差异更小且混合。错误的早期答案往往把概率集中在所选选项上，因此更早停止并不统一改善概率质量。在这些测试中，紧期限可以偏向较低努力或简洁指令，而让高努力完成可以恢复更高的最终准确率。评估应分别报告期限前的正确完成、运行停止时获得的答案、未完成运行间的差异，以及分配给正确答案的概率。

## 摘要

- 提出 OPOD（在线策略全模态蒸馏）：把文本、图像与音频教师整合进一个全模态模型——把每个响应路由到对应教师、独立控制教师，并仅在教师对生成 token 赋予更高概率时应用引导；所选教师还评估答案置信度以及推理是否增加对答案的支持。
- 全模态模型提供文本、图像与音频的统一接口；然而共同提升这些能力仍困难，因为池化多模态数据上的训练后微调往往无法保持模态教师的优势；标准 OPD 不易扩展到多个模态教师（其引导可能偏向冲突的共享模型改变，而匹配每个教师的下一 token 分布可能阻止学生超越该教师）。
- 十二个基准的大量实验显示 OPOD 在三个模型规模取得最佳平均（70.8、51.7 与 46.2），超过最强比较者 2.1、1.8 与 1.7 分。
- 30B 时在所有十二个基准上超过基础模型与池化 RL 训练，且即使纳入教师也在十一个上排名第一或第二；部署只保留学生。

## 正文

论文编号：arXiv:2607.20918v3（更新类型：replace）。以下为摘要全文翻译。

全模态模型为文本、图像与音频提供统一接口。然而，共同提升这些能力仍然困难，因为在池化多模态数据上的训练后微调往往无法保持模态教师的优势。在线策略蒸馏（OPD）近来在模型训练后微调中流行起来。它从当前学生采样响应，并沿着这些响应比较教师与学生的下一 token 分布，产生密集监督，同时减少训练与推理之间的错配。尽管有这些优势，标准 OPD 不易扩展到多个模态教师。它们的引导可能偏向对共享模型相互冲突的改变，而匹配每个教师的下一 token 分布可能阻止学生超越该教师。为应对这些挑战，我们提出 OPOD（On-Policy Omni Distillation，在线策略全模态蒸馏），把文本、图像与音频教师整合为一个全模态模型。OPOD 把每个响应路由到对应的教师，独立控制教师，并且只在教师对生成 token 赋予更高概率时应用引导。所选教师还评估答案置信度，以及推理是否增加对答案的支持。在十二个基准上的大量实验表明，OPOD 在三个模型规模取得最佳平均分（70.8、51.7 与 46.2），超过最强比较者 2.1、1.8 与 1.7 分。在 30B 规模，它在全部十二个基准上超过基础模型与池化 RL 训练，并且即使把教师纳入比较，也在十一个上排名第一或第二。部署时只保留学生。

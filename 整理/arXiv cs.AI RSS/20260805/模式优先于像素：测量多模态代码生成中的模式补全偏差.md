# 模式优先于像素：测量多模态代码生成中的模式补全偏差

## 摘要

- 引入首个视觉模式补全偏差基准：重复 UI 模式中一个局部元素被扰动，模型必须从截图与 HTML 上下文恢复被掩码的宽度或字号值——从 Design2Code 数据集策展的 30 个网页出发，构建 1,440 个评估截图，覆盖结构卡片与文本样式模式的标准与噪声叠加条件。
- 五个前沿 MLLM 都强烈偏向重复基线：平均偏差率在卡片宽度扰动上达 69.78%、文本字号扰动上达 80.22%，而平均准确率分别仅 21.17% 与 7.89%。
- Codex-5.3 表现最佳，但仍从卡片 68.61% 准确率跌到文本 13.89%；Flash-3.0 在文本上达 96.11% 偏差；噪声、更细微扰动与边界位置进一步提高偏差率。
- 推理分析显示更大推理努力与更低偏差相关，但定性证据表明模型能识别异常元素仍用模式一致答案覆盖它——多模态代码生成的具体失败模式，其严重性与视觉显著性强相关。

## 正文

论文编号：arXiv:2608.03691v1（更新类型：cross）。以下为摘要全文翻译。

多模态大语言模型（MLLM）日益被用于把网页截图翻译为前端代码，但重复的 UI 模式可能把它们引向视觉不正确却模式一致的输出。在本工作中，我们测试重复网页模式如何在客观的截图到代码填空任务上损害 MLLM 准确率。我们引入第一个视觉模式补全偏差基准：重复 UI 模式中的一个局部元素被扰动，模型必须从截图与 HTML 上下文恢复被掩码的宽度或字号值。从 Design2Code 数据集策展的 30 个网页出发，我们构建 1,440 个评估截图，涵盖结构卡片与文本样式模式的标准与噪声叠加条件。我们评估五个前沿 MLLM，发现它们都强烈偏向重复基线：平均偏差率在卡片宽度扰动上达到 69.78%，在文本字号扰动上达到 80.22%，而平均准确率分别只有 21.17% 与 7.89%。Codex-5.3 表现最佳，但仍从卡片上的 68.61% 准确率跌到文本上的 13.89%，而 Flash-3.0 在文本上达到 96.11% 的偏差。噪声、更细微的扰动与边界位置进一步提高偏差率。推理分析进一步表明，更大的推理努力与更低的偏差相关，然而定性证据揭示，模型可以识别异常元素，却仍用模式一致的答案覆盖它。我们的结果识别出多模态代码生成中的一个具体失败模式，并表明其严重性与视觉显著性强烈相关。

## 摘要

- OpenAI 前沿模型和 Codex 现已通过 AWS 全面可用。
- 为企业提供一条借助其已使用的 AWS 环境、控制和采购流程来构建 OpenAI 应用的新路径；客户可以在 AWS 上快速从评估走向生产。

## 正文

OpenAI 前沿模型和 Codex 现已通过 AWS 全面可用，为企业提供了一条新路径：通过他们已经在使用的 AWS 环境、控制和采购工作流，使用 OpenAI 进行构建。客户可以从在 AWS 上开始使用 OpenAI，更快地从评估走向生产。

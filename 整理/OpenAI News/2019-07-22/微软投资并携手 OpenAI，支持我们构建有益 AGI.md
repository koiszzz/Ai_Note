# 微软投资并携手 OpenAI，支持我们构建有益 AGI

## 摘要

- 微软向 OpenAI 投资 10 亿美元，支持我们构建经济收益广泛分布的通用人工智能（AGI）。
- 双方合作在 Microsoft Azure 内开发可扩展至 AGI 的硬件和软件平台，共同开发新的 Azure AI 超算技术。
- 微软将成为 OpenAI 的独家云服务提供商。

## 正文

微软向 OpenAI 投资 10 亿美元，支持我们构建经济收益广泛分布的通用人工智能（AGI）。我们正在合作，在 Microsoft Azure 内开发一个能够扩展至 AGI 的硬件和软件平台。我们将共同开发新的 Azure AI 超算技术，微软将成为我们的独家云服务提供商——因此我们将携手努力，进一步扩展 Microsoft Azure 在大规模 AI 系统方面的能力。

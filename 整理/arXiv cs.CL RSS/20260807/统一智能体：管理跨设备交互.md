- 构建跨设备与时间的用户-智能体交互基准比较状态设计；在 Unified Agent 中实例化该原则——有状态智能体跨设备与时刻携带交互证据并配合当前观察行动；默认设置下显著优于四个已发表设计的适配，跨 MLLM 家族、能力与推理努力变化保持领先，展示状态设计优势跨 MLLM 设置稳健。

## 正文

随着能力迅速提升，AI 智能体可以从在单一应用内运行，转向随时间跨用户设备行动。然而，现有智能体系统在此场景中仍显不足。这是因为观察散布于设备与时刻之间，而主流系统并非围绕这一事实设计：将设备视为工具的单一智能体缺乏跨时间对所有设备的有效状态管理，多智能体系统则跨智能体进行协调，但不维护跨设备、跨时间请求所需的紧凑携带状态（compact carried state）。研究主张，智能体应维护一个有效设计的状态：将参与证据（engagement evidence）、陈述事实（stated facts）与持续请求（standing request）以紧凑、可行动的形式组织起来，用于在当前观察下决定行动。为比较状态设计，研究构建了一个跨设备与时间的用户-智能体交互基准。研究在 Unified Agent 中实例化了这一原则——一个跨设备与时刻携带交互证据、并配合当前观察采取行动的有状态智能体。在默认设置下，它显著优于研究对四个已发表设计的适配。跨多模态大语言模型（MLLM）家族、能力与推理努力的变化，它始终领先于所有对比系统，展示了状态设计优势在 MLLM 设置下的稳健性。代码与数据将在 GitHub 公开。

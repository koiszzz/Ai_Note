# 示例引导提示用于文档级文本简化

## 摘要

- 文档级文本简化要求 LLM 重写复杂文档，同时保留意义、可读性与话语连贯性；提示基 LLM 虽有前景性能，但因文本指令单独对复杂文档级转换提供有限引导，常产生不一致简化。
- 考察检索文档简化示例能否改进文档级生成：用从平行简化语料选择的示例增广提示。
- 该示例引导提示方法使 LLM 无需任务特定微调即利用相关简化模式；OneStopEnglish 语料多个 SOTA LLM 实验显示纳入检索示例一致改进简化质量（相对仅提示生成），并与代表性监督（T5）与规划基（PlanSimp）文档简化系统竞争或更优。

## 正文

文档级文本简化要求大语言模型（LLMs）重写复杂文档，同时保留意义、可读性与话语连贯性。虽然基于提示的 LLM 显示出有前景的性能，它们常常产生不一致的简化，因为单独的文本指令对复杂的文档级转换提供的引导有限。研究考察检索到的文档简化示例能否改进文档级生成：通过用从平行简化语料中选择的示例增广提示。这种示例引导的提示方法使 LLM 能够利用相关的简化模式，而无需任务特定的微调。在 OneStopEnglish 语料上使用多个最先进 LLM 的实验表明，纳入检索到的示例一致改进简化质量，优于仅提示生成，并与代表性的监督（T5）与基于规划（PlanSimp）的文档简化系统实现竞争或更优的性能。此外，研究发现示例引导提示的收益跨 LLM 而异，表明有效使用检索示例取决于模型在生成期间整合上下文信息的能力。

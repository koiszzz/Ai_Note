# 语言模型的层级潜预测

## 摘要

- 标准下一 token 预测（NTP）奠定语言模型预训练基础，但其教师强制训练范式对长时程推理与规划可能非最优。
- 多 token 预测（MTP）与下一潜预测（NextLat）等近期工作经预测多个未来 token 与潜空间自监督预测缓解问题，但这些辅助目标要么视界有限、要么受多步 rollout 复合误差困扰。
- 引入层级潜预测（HiLP）：引入辅助更高级抽象潜变量，帮助减少潜空间 rollout 误差累积效应。
- 实验显示 HiLP 可实现更长视界连贯信念状态表征，编码与多步推理基准上证明方法有效性，并提供更高投机解码效率。

## 正文

标准下一 token 预测（Next-Token Prediction, NTP）奠定了语言模型预训练的基础，然而其教师强制的训练范式可能对长时程推理与规划不是最优的。多 token 预测（Multi-Token Prediction, MTP）与下一潜预测（Next-Latent prediction, NextLat）等近期工作试图通过预测多个未来 token 与在潜空间中进行自监督预测来缓解该问题。然而，这些辅助目标要么视界有限，要么遭受多步 rollout 的复合误差。研究引入层级潜预测（Hierarchical Latent Prediction, HiLP），它引入一个辅助的更高层级抽象潜变量，帮助减少潜空间 rollout 中的误差累积效应。实验表明，HiLP 可以实现更长视界的连贯信念状态表征，在编码与多步推理基准上展示方法的有效性，并提供更高的投机解码效率。

## 正文

工具使用将 LLM 转变为在训练数据之外行动的智能体；对于具备代码能力的模型，程序化工具调用（programmatic tool calling, PTC）通过用可自然链接与并行化的脚本替换僵硬的 JSON 调用，进一步延伸了这一能力。然而，在真实世界任务条件下、跨当前与先前模型世代，对工具作为代码在既有基准上的系统评估尚未进行。在这项工作中，研究在 BFCL v4 上对 14 个语言模型实证比较了程序化工具调用与原生 JSON 工具调用。在程序化工具调用范式中，工具以类型化 Python 桩（typed Python stubs）暴露，模型通过代码调用它们，执行与结果在单个智能体回合内处理。程序化工具调用在 BFCL v4 的 14 个模型中的 11 个上匹配或超越原生 JSON 工具调用，其中 GPT-5.6 家族较 JSON 工具调用基线实现了 10.6% 的改进。此外，在并行扇出（parallel fan-out）下，它在 14 个模型中的 13 个上匹配或超越基线，并在上下文腐烂（context rot）条件下保持稳定，而基线平均退化 2.3%。结果表明，程序化工具调用是 JSON 工具调用的可行且稳健的替代方案，其性能随发布世代的模型能力而跟踪。

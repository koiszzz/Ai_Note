## 摘要

- 多语言评测只在单一输出 token 上限下报告准确率，但不同语言表达相同内容所需的 token 数量不同，因此该上限是一个隐藏的实验变量。
- 在四种提示策略下、对 Qwen3-8B 和 Llama-3.1-8B-Instruct 检验 MGSM（德语、泰语、斯瓦希里语）上的母语-翻译差距是否为 token 预算伪影：测得差距随预算最多摆动 57 个点，长度归一化在预算受限时最多移动 38.9 个点，紧预算下归一化甚至可能颠倒策略之间的得分排序。
- 预先冻结扫描中 Qwen 的三个峰值及 1024 处的近零值，在 540,000 次独立硬上限解码上评估：第二个冻结家族（六个 Holm 校正检验）拒绝了所有原假设；冻结检验在 $B^*=1024$ 仍无法拒绝，因为母语准确率已在该处饱和，饱和以上残余差异是策略性能差距而非推理缺陷。
- 同一截断通道支撑了成本排序的适配阶梯：跨拟合的泰语词汇扩展在冻结预算下只缩小 0.0 个点的差距，而在 19% 轨迹仍被截断处缩小 4.9 个点。
- 第三个冻结家族只改变宣布的预算而强制上限固定：宣布 128 而非 2048 个 token 使泰语母语准确率移动 5.1 个点，因此准确率并非仅由强制上限决定。结论：把输出上限当作自变量，跨预算区间报告准确率，而不是在单一预算处报告。

## 正文

多语言评测在单一输出 token 上限下报告准确率，但不同语言表达相同内容需要的 token 数量不同，因此上限是一个隐藏的实验变量。我们在四种提示策略下检验 MGSM（德语、泰语、斯瓦希里语）上的母语-翻译差距对 Qwen3-8B 和 Llama-3.1-8B-Instruct 而言是否是 token 预算伪影。

测得差距随预算最多摆动 57 个点；在预算受限处，长度归一化最多将其移动 38.9 个点；在紧预算下，归一化甚至可能颠倒哪个策略得分更高。我们预先冻结了扫描中 Qwen 的三个峰值及其在 1024 处的近零值，并在 540,000 次独立硬上限解码上对它们进行评估：第二个冻结的六检验家族（经 Holm 校正）拒绝了每一个原假设。在 $B^*=1024$ 处的冻结检验仍然无法拒绝，因为母语准确率在那里已经饱和；在饱和点之上，残余差异是策略性能差距，而不是已识别的推理缺陷。

同样的截断通道还为一个按成本排序的适配阶梯定价：一个交叉拟合的泰语词汇扩展在冻结预算下缩小 0.0 个点的差距，而在 19% 的轨迹仍被截断处缩小 4.9 个点。第三个冻结家族在强制上限固定的情况下只改变宣布的预算：宣布 128 个而非 2048 个 token，会使泰语母语准确率移动 5.1 个点，因此准确率并非强制上限的单一函数。

从一次长上限运行计算出的"正确发射时序恒等式"（correct-emission timing identity）与三个预先指定的 MGSM 峰值吻合到 0.65 个点，并且在另外三个基准的探索性仅 Qwen 分析中，对保留样本的追踪达到 0.92 个点，在七个单元中的五个中精确定位了峰值。请把输出上限当作自变量来对待，并跨预算区间报告准确率，而不是在单一预算处报告。

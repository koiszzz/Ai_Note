# 终端智能体足以胜任企业自动化

## 摘要

- 业界对能自主与数字平台交互、执行有意义企业任务的智能体兴趣日增，主流路线包括基于 Model Context Protocol（MCP）等抽象的工具增强智能体，以及通过图形界面操作的网页智能体。
- 本文论证：仅配备终端和文件系统的编码智能体，通过直接与平台 API 交互，能更高效地解决许多企业任务。
- 在多种真实世界系统上的评估表明，这些底层终端智能体以极低代价达到或超越更复杂的智能体架构；简单灵活的程序化接口加强大基础模型应成为企业自动化的骨干。

## 正文

业界对构建能够与数字平台交互、自主执行有意义企业任务的智能体兴趣日益增长。在已探索的方法中，有基于 Model Context Protocol（MCP）等抽象构建的工具增强智能体，也有通过图形界面操作的网页智能体。然而，鉴于此类复杂智能体系统的成本与运营开销，它们是否必要仍不清楚。我们论证，一个仅配备终端和文件系统的编码智能体，通过直接与平台 API 交互，可以更有效地解决许多企业任务。我们在多样的真实世界系统上评估了这一假设，结果表明这些底层终端智能体以极低代价达到或超越了更复杂的智能体架构。我们的发现表明，简单灵活的程序化接口与强大的基础模型相结合，应成为企业自动化的骨干。

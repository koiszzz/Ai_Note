# 潜在去噪提升大型多模态模型的视觉对齐

> [!info] 来源信息

## 摘要

- 提出潜在去噪框架：用显著性感知的掩蔽与高斯加噪破坏视觉 token，训练 LMM 从中间层隐藏状态恢复干净的教师 patch 特征，为视觉 token 提供直接监督。
- 通过保留教师图像内相似性结构与图像内对比 patch 蒸馏防止表征坍缩；推理时无额外开销。
- 在标准多模态基准与组合鲁棒性基准（如 NaturalBench）上一致提升，且在 ImageNet-C 式常见损坏下退化更少。

## 正文

大型多模态模型（LMM）如 LLaVA 通常以自回归语言建模目标训练，仅向视觉 token 提供间接监督。这常导致内部视觉表征较弱，且在分布偏移下表现脆弱。受近期在潜空间去噪用于学习高质量视觉 tokenizer 方面进展的启发，我们表明同样的原理可以作为一种有效的视觉监督形式，用于改进 LMM 的内部视觉特征对齐和多模态理解。

我们提出一个潜在去噪框架，使用显著性感知的掩蔽与高斯加噪混合方式破坏投影后的视觉 token。LMM 被训练通过解码器从选定的中间 LLM 层的隐藏状态恢复干净的教师 patch 特征，从而对这些被破坏的 token 去噪。为防止表征坍缩，我们的框架还保留教师的图像内相似性结构，并应用图像内对比 patch 蒸馏。

推理期间，扰动与辅助头均被禁用，不引入任何额外推理开销。在广泛的标准多模态基准上，我们的方法一致地提升视觉理解与推理，优于强基线，并在组合鲁棒性基准（如 NaturalBench）上带来明显增益。此外，当对基准图像应用 ImageNet-C 式非对抗性常见损坏时，我们的方法在中等和严重损坏水平下均保持更高准确率且退化更少。我们的代码可在 https://github.com/dhruvashp/latent-denoising-for-lmms 获取。

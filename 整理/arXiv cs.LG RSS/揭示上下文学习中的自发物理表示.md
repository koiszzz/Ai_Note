# 揭示上下文学习中的自发物理表示

## 摘要

- 上下文学习（ICL）让大语言模型（LLM）仅凭提示解决新任务，领域日益广泛，但支撑该能力的机制仍知之甚少。
- 物理系统为这一问题提供受控测试平台：提供实验可控、具有植根于基本原理的结构化动力学的数据。
- 研究 LLM 的 ICL 能力，聚焦物理推理：用动力学预测作为代理任务，首先表明 LLM 在上下文中预测物理动力学，准确率随提供更多历史而提升。
- 分析模型残差流揭示与能量等关键物理量相关的内部激活：这些相关随上下文长度逐步增强，表明 LLM 在无任何物理特定监督的情况下自发形成与物理概念对齐的表示。
- 引入逐层基于梯度的归因分析评估这些表示是否贡献于模型预测：与能量相关更强的残差方向也获得对数值预测更大的归因。
- 该模式未在位移等直接观测量的相关特征中观察到，表明能量相关信号不只是从输入复制的数值信息。
- 结果把 ICL 分析扩展到结构化物理动力学，并对 LLM 如何在上下文中组织物理结构给出机制说明。

## 正文

论文编号：arXiv:2508.12448v2（更新类型：replace-cross）。以下为摘要全文翻译。

上下文学习（ICL）让大语言模型（LLM）仅凭提示即可解决新任务，领域日益广泛，然而支撑这一能力的机制仍然知之甚少。物理系统为这个问题提供了一个受控测试平台，因为它们提供实验可控的数据，具有植根于基本原理的结构化动力学。在此我们研究 LLM 的 ICL 能力，聚焦物理推理。使用动力学预测作为代理任务，我们首先表明 LLM 在上下文中预测物理动力学，且准确率随提供更多历史而提高。分析模型的残差流揭示与能量等关键物理量相关的内部激活。这些相关随上下文长度逐步增强，表明 LLM 在没有任何物理特定监督的情况下自发形成与物理概念对齐的表示。为评估这些表示是否对模型的预测有贡献，我们引入一种逐层的基于梯度的归因分析。我们发现，与能量相关更强的残差方向也获得对数值预测更大的归因。位移等直接观测量的相关特征中未观察到该模式，表明能量相关信号不只是在输入中复制的数值信息。我们的结果把 ICL 分析扩展到结构化物理动力学，并对 LLM 如何在上下文中组织物理结构提供了机制性说明。

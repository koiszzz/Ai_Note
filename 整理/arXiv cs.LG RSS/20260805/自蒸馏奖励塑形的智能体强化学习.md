## 摘要

- 引入带自蒸馏奖励塑形的智能体强化学习（ADRS），为多轮语言智能体构建与回报关联的 token 级信用的框架：在每步内居中并归一化特权 token 分数，用基于组内置信度-回报关联的回报关联教师值优势（TVA）门调制它们，并把门控 token 信号纳入原生 RL 信用构建——共同决定教师偏好什么、该偏好何时与回报相关、以及它如何进入原生强化学习信用路径，同时保持 rollout 与推理无技能。
- 智能体强化学习使 LLM 智能体能通过交互学习，但稀疏轨迹级奖励揭示成功，却未识别哪些中间决策应获信用；仅训练特权技能可提供更密集监督：相同冻结策略快照在条件于任务匹配过程性技能时重打分无技能轨迹的固定 token。
- 现有方法未联合跨交互步骤校准教师分数、未把教师置信度与实现回报关联、未把所得信号整合进原生奖励到优势构建。
- 三个交互基准实验显示 ADRS 一致改善长视界任务性能，增益跨 RL 骨干、缩减数据设置、未见任务与扩展训练持续；匿名评审代码：https://github.com/gitrxh/ADRS-arxiv

## 正文

论文编号：arXiv:2608.03223v1（更新类型：new）。以下为摘要全文翻译。

智能体强化学习使 LLM 智能体能够通过交互学习，但稀疏的轨迹级奖励揭示了成功，却没有识别哪些中间决策值得获得信用。仅训练的特权技能可以提供更密集的监督：允许同一冻结策略快照在条件于任务匹配的过程性技能时，对无技能轨迹中的固定 token 重新评分。然而，现有方法不跨交互步骤联合校准教师分数、不把教师置信度与实现的回报联系起来、也不把所得信号整合进原生的奖励到优势构建。我们引入带自蒸馏奖励塑形的智能体强化学习（Agentic Reinforcement Learning with Self-Distilled Reward Shaping，ADRS），一个为多轮语言智能体构建与回报关联的 token 级信用的框架。ADRS 在每一步内居中并归一化特权 token 分数，用基于组内置信度-回报关联的回报关联教师值优势（Teacher Value Advantage，TVA）门调制它们，并把门控的 token 信号纳入原生 RL 信用构建。这些组件共同决定教师偏好什么、该偏好何时与回报相关、以及它如何进入原生强化学习信用路径，同时保持 rollout 与推理无技能。最后，三个交互基准的实验表明，ADRS 一致改善长视界任务的性能，增益跨 RL 骨干、缩减数据设置、未见任务与扩展训练持续存在。匿名评审代码可在以下链接获取：https://github.com/gitrxh/ADRS-arxiv

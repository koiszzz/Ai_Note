## 摘要

- 大语言模型常在回答前长篇推理，增加成本与延迟；提示与训练设置可缩短推理，但更短轨迹可能只说明模型更早停止。
- 评估 198 个 GPQA Diamond 与 500 个 MMLU-Pro 问题上匹配推理视界的配对运行：测试为 Qwen3-14B 宣布 token 限制的数字/简洁提示，以及 gpt-oss-20b 与 -120b 的训练努力设置。
- Qwen 提示把推理轨迹缩短 12–17%，匹配 token 限制下准确率变化小且混杂；简洁/早答指令在 512 token 处把 MMLU-Pro 准确率提升 3.8 个百分点，包括双方都未完成时 +2.7 点；其 2,048 token 处增益不确定。
- gpt-oss 上，从完成低与中努力推理的候选 logit 答案比匹配视界的高努力答案准确 14.5–26.3 点；512-token 优势大多来自低努力更早完成，未完成运行间差异较小且混杂。
- 错误早答常把概率集中在所选选项，因此更早停止并不一致改善概率质量。
- 这些测试中，紧迫截止有利于较低努力或简洁指令，而允许高努力完成可恢复更高最终准确率；评估应分别报告截止前正确完成、运行停止时所得答案、未完成运行间差异与正确答案上的概率。

## 正文

论文编号：arXiv:2608.03401v1（更新类型：new）。以下为摘要全文翻译。

大语言模型往往在回答之前进行长篇推理，增加成本与延迟。提示与训练设置可以缩短这种推理，但更短的轨迹可能只表明模型更早停止。在这里，我们在 198 个 GPQA Diamond 与 500 个 MMLU-Pro 问题上评估匹配推理视界的配对运行。我们测试一个为 Qwen3-14B 宣布 token 限制的数字/简洁提示，以及 gpt-oss-20b 与 -120b 的训练努力设置。Qwen 提示把推理轨迹缩短 12–17%，而匹配 token 限制下准确率的变化小且混杂。一个简洁/早答指令在 512 token 处把 MMLU-Pro 准确率提升 3.8 个百分点，包括双方运行都未完成时的 +2.7 点。它在 2,048 token 处的增益不确定。对 gpt-oss，来自已完成低与中努力推理的候选 logit 答案比匹配视界的高努力答案准确 14.5–26.3 点。512-token 优势的大部分来自较低努力更早完成，而未完成运行之间的差异较小且混杂。错误的早答往往把概率集中在所选选项上，因此更早停止并不一致地改善概率质量。在这些测试中，紧迫的截止时间可能有利于较低努力或简洁指令，而允许高努力完成可以恢复更高的最终准确率。评估应分别报告截止时间前的正确完成、运行被停止时获得的答案、未完成运行之间的差异，以及分配给正确答案的概率。

# 先逻辑后语言：形式推导上的预预训练促进技能习得与可压缩性

## 摘要

- 在符号数据上预预训练语言模型（LM）能加速并改善自然语言习得；但 Dyck 与过程算法等现有预预训练任务依赖无法捕捉自然语言表达能力的狭窄原语，且先前研究局限于相对较小的 token 预算，对技能涌现与表示动力学的洞见有限。
- 提出逻辑预预训练（Logic-PPT）作为有原则的初始化策略：利用形式推导赋予更丰富的结构与语言偏置。
- 形式推导需要自然语言的核心抽象机制：同时绑定变量、连接量词与关系依赖、在长上下文上组合谓词—参数结构。
- 把评估扩展到 100B token 规模：逻辑预预训练显著加速 LM 的技能习得，比标准初始化少用 36B token 即在语言任务上达到 80% 准确率，并优于其他预预训练基线。
- 机制上，形式推导诱发持久的结构重组，其显著特征是更低秩、谱集中的表示空间。
- 关键发现：这种内部几何通过剪枝实现更优模型可压缩性，即使在约 33% 稀疏度下仍匹配密集基线性能。

## 正文

论文编号：arXiv:2608.03930v1（更新类型：cross）。以下为摘要全文翻译。

在符号数据上预预训练语言模型（LM）可以加速并改善自然语言习得。然而，Dyck 与过程算法等现有预预训练任务依赖无法捕捉自然语言表达能力的狭窄原语。此外，先前研究仍局限于相对较小的 token 预算，对技能涌现与表示动力学的洞见有限。为应对这些局限，我们提出逻辑预预训练（Logic-PPT）作为有原则的初始化策略，利用形式推导赋予更丰富的结构与语言偏置。形式推导需要自然语言的核心抽象机制：同时绑定变量、连接量词与关系依赖、并在长上下文上组合谓词—参数结构。把评估扩展到 100B token 规模后，逻辑预预训练显著加速 LM 的技能习得，比标准初始化少用 36B token 即在语言任务上达到 80% 的准确率，并优于其他预预训练基线。机制上，形式推导诱发持久的结构重组，其显著特征是更低秩、谱集中的表示空间。关键的是，我们表明这种内部几何通过剪枝实现更优的模型可压缩性，即使在约 33% 的稀疏度下也匹配密集基线的性能。

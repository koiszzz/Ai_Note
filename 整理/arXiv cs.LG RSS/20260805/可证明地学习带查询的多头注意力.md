# 可证明地学习带查询的多头注意力

## 摘要

- 研究从黑箱输入输出访问学习多头 softmax 注意力的问题：学习者可查询任意实值 token 序列，只观察最后 token 的标量输出。
- 近期工作给出用 O(d²) 次值查询恢复单头参数 (W,v) 的算法；多头方面，同一工作证明在头占据成对正交子空间的假设下可识别；单独对每个头应用单头恢复算法还需要这些子空间的基已知。
- 通过合并具有相同 W_h 的头（把相应 v_h 相加、和为零时丢弃合并头）恢复规范表示，无需这些子空间假设：通过变化 token 的副本数，算法获得一个有理函数的样本，其插值分离规范头；加入所选 token 向量的附加查询随后跨不同查询匹配同一头。
- 当预言机输出与后续所有计算精确时，学习者随机选择查询向量，以概率 1 恢复规范对 {(W_h,v_h):h∈[H]}（至置换）；H 已知时恰好用 4Hd²−2H+1 次最大长度 2H+1 的值查询；只有已知上界 H0 时用 4H0d²−2H0+1 次最大长度 2H0+1 的查询。
- 对近似预言机输出，给出参数误差最多为模型与查询依赖常数乘输出误差的条件。
- 最后把结果扩展到带多头注意力后接无偏置 ReLU 前馈网络的一层 Transformer：附加条件下，恢复功能等价的 Transformer，无需依赖学习前馈网络的独立算法。

## 正文

论文编号：arXiv:2608.03294v1（更新类型：new）。以下为摘要全文翻译。

我们研究从黑箱输入输出访问学习多头 softmax 注意力的问题。学习者可以查询任意实值 token 序列，只观察最后 token 处的标量输出。近期工作给出一个使用 O(d²) 次值查询恢复单头参数 (W,v) 的算法。对多个头，同一工作证明在头占据成对正交子空间的假设下可识别性。单独对每个头应用单头恢复算法，还需要这些子空间的基已知。我们在没有这些子空间假设的情况下，通过合并具有相同 W_h 的头（把相应 v_h 相加、并在该和为零时丢弃合并后的头）恢复一个规范表示。通过变化一个 token 的副本数，我们的算法获得一个有理函数的样本，其插值分离规范头。通过加入所选 token 向量形成的额外查询，随后跨不同查询匹配同一个头。当预言机输出及所有后续计算精确时，学习者随机选择查询向量，并以概率 1 恢复规范对 {(W_h,v_h):h∈[H]}（至置换）。当 H 已知时，它恰好使用 4Hd²−2H+1 次最大长度 2H+1 的值查询。如果只有已知上界 H0 可用，算法使用 4H0d²−2H0+1 次最大长度 2H0+1 的值查询。对近似预言机输出，我们给出参数误差最多为模型与查询依赖常量乘输出误差的条件。最后，我们把结果扩展到带多头注意力后接无偏置 ReLU 前馈网络的一层 Transformer。在附加条件下，我们恢复一个功能等价的 Transformer，而无需依赖学习前馈网络的独立算法。

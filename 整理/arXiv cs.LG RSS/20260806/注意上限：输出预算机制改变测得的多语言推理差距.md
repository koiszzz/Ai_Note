# 注意上限：输出预算机制改变测得的多语言推理差距

## 摘要

- 在单一输出 token 上限下报告多语言评估准确率，但不同语言表达相同内容所需 token 数不同，因此上限是隐藏的实验变量
- 以 Qwen3-8B 与 Llama-3.1-8B-Instruct 在四种提示策略下测试 MGSM（德语、泰语、斯瓦希里语）上的母语-翻译差距：测得差距跨预算摆动最高达 57 分，长度归一化在上限约束处移动最高 38.9 分
- 结论：应将输出上限视为自变量，跨预算机制报告准确率，而非在单一预算下报告

## 正文

多语言评估在单一输出 token 上限下报告准确率，但不同语言表达相同内容需要不同数量的 token，因此该上限是一个隐藏的实验变量。我们测试了在 MGSM（德语、泰语、斯瓦希里语）上，Qwen3-8B 与 Llama-3.1-8B-Instruct 在四种提示策略下的母语-翻译差距是否为 token 预算假象。测得差距跨预算摆动最高达 57 分；在预算上限约束生效时，长度归一化使其移动最多 38.9 分；在严格上限下，归一化甚至可能颠倒各策略的得分高低。我们预先冻结了扫描中 Qwen 的三个峰值以及其在 1024 处接近零的值，并在 540,000 次独立硬上限解码上对其进行评估：第二个冻结族（六个 Holm 校正检验）拒绝了每一个零假设。在 `$B^*=1024$` 处的冻结检验仍然无法拒绝，因为母语准确率在那里已经饱和；超过饱和点后，残余差异是策略性能差距，而非已识别的推理缺陷。同一条截断通道还为一个成本排序的适配阶梯定价：交叉拟合的泰语词汇扩展在冻结预算下缩小 0.0 分差距，而在 19% 的轨迹仍被截断处缩小 4.9 分。第三个冻结族只改变对外宣布的预算而保持实际强制上限固定：宣布 128 而非 2048 个 token 使泰语母语准确率移动 5.1 分，因此准确率并不只是强制上限的函数。由一次长上限运行计算得到的正确发射时序恒等式，与三个预先指定的 MGSM 峰值匹配到 0.65 分；在另外三个基准的探索性仅 Qwen 分析中，对留出项跟踪到 0.92 分，并在七个单元格中的五个精确定位了峰值。请将输出上限视为自变量，并在预算机制范围内报告准确率，而非在单一预算下报告。

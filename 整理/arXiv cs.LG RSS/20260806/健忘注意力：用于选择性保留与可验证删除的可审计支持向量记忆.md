# 健忘注意力：用于选择性保留与可验证删除的可审计支持向量记忆

> [!info] 来源信息

## 摘要

- 提出支持向量注意力（SV-Attention）：单类 SVDD 门，其系数进入读出层，支持无重求解的 token 移除
- 1,200 次 fp64 删除/重拟合试验中 1,199 次完成，全新重拟合比维护式删除慢 24-223 倍
- 稀有组召回率 0.861 对 oracle 代理的 0.319；ICU 事件小时保留率 0.464 对 RBF 基线的 0.225

## 正文

可审计的记忆需要一个精确的契约：保留哪个输出、相对于哪个参考求解（reference solve）、以及跨越哪些更新。我们引入支持向量注意力（Support Vector Attention, SV-Attention），一种单类支持向量数据描述（SVDD）门，其系数进入读出层（readout）。零系数键是储备键（reserve），正系数键是活跃键（active）。在不重新求解的情况下移除储备 token 会保留当前读出。维护式删除（maintained deletion）更新现有求解器状态，在相同系数上限 C 下针对新的保留键拟合（retained-key fit）。

在 Gaussian、冗余（redundant）、MIMIC-IV 和学到的键上进行的 1,200 次 fp64 删除/重拟合试验中，1,199 次完成。在已声明探针上的中位最大门分数差异范围从 4.5e-13 到 5.7e-7，并且在参考 CPU 上，全新重拟合比维护式删除慢 24-223 倍。一个确定性示例表明，当前的储备状态并不能保证未来接纳（admission）之后的等价性。

在匹配的 token 数下，稀有组召回率为 0.861，而 oracle 注意力质量代理（H2O 风格）为 0.319。在留出通道（held-out-channel）的 ICU 对照中，SpO2 低于 90% 定义事件，但 SpO2 被排除在每个选择器之外；事件小时保留率为 0.464，而 RBF 密度基线为 0.225。一个单独的分批近似支持端到端训练；在 3.22M 参数下，七对配对种子的平均最佳验证每字符比特数为 2.178 对 2.383（p=0.001）。

这些契约是时点性的且固定 C 的；面向未来的流式处理与通用性能仍待解决，而更大的固定步长运行表明优化速度较慢。

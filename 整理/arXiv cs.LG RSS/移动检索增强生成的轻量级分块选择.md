# 移动检索增强生成的轻量级分块选择

## 摘要

- RAG 通过引入外部知识改善 LLM 的事实接地，但把 RAG 部署到移动与边缘设备仍具挑战性，因为检索到的上下文增加计算与内存。
- 降低成本的直接方式是在生成前只保留一个检索到的分块，但排名最靠前的检索分块并不总是证据支持最强的，因为检索相似性不一定意味着证据充分性。
- 现有上下文缩减方法能改善上下文质量，但常需要额外的 LLM 或压缩器，在严格的移动预算下成本高昂。
- 把轻量级 RAG 分块选择研究为证据对齐问题：选择器结合三类互补特征源——表示 LLM 侧查询意图的问题隐藏状态、捕捉生成器内部路由结构的 MoE 路由导出专家信号、以及保持候选侧证据几何的检索分块嵌入。
- 紧凑多层感知机把这些特征映射到分块嵌入空间中的证据原型，用余弦相似度选择与该原型最对齐的候选；针对更严格部署预算，还引入可选的任务感知特征选择策略以降低选择器输入维度。
- 为支持监督评估，基于证据充分性而非答案字符串包含构建语义分块正确性标签；实验表明所提选择器在移动适用基线上平均把 rank-1 证据选择提升 2.5%，说明使用 LLM 侧查询表示与 MoE 路由信息并使其与检索侧候选嵌入对齐，是移动适用 RAG 分块选择的有效且参数高效策略。

## 正文

论文编号：arXiv:2608.03148v1（更新类型：new）。以下为摘要全文翻译。

RAG 通过引入外部知识改善 LLM 的事实接地，但把 RAG 部署到移动与边缘设备仍具挑战性，因为检索到的上下文会增加计算与内存。降低这种成本的直接方式是在生成前只保留一个检索到的分块，但排名最靠前的检索分块并不总是证据支持最强的那个，因为检索相似性不一定意味着证据充分性。现有上下文缩减方法可以改善上下文质量，但常常需要额外的 LLM 或压缩器，这在严格的移动预算下成本高昂。在本文中，我们把轻量级 RAG 分块选择研究为证据对齐问题。我们的选择器结合三类互补特征源：表示 LLM 侧查询意图的问题隐藏状态、捕捉生成器内部路由结构的 MoE 路由导出专家信号、以及保持候选侧证据几何的检索分块嵌入。一个紧凑的多层感知机把这些特征映射到分块嵌入空间中的证据原型，并通过余弦相似度选择与该原型最对齐的候选。为应对更严格的部署预算，我们进一步引入一个可选的任务感知特征选择策略，以降低选择器输入维度。为支持监督评估，我们基于证据充分性而非答案字符串包含构建语义分块正确性标签。实验表明，所提选择器在移动适用基线上平均把 rank-1 证据选择提升 2.5%。这些结果表明，使用 LLM 侧查询表示与 MoE 路由信息并使其与检索侧候选嵌入对齐，是移动适用 RAG 分块选择的一种有效且参数高效的策略。

# 深度学习受控粒子系统的收敛分析：从有限到无限样本

## 摘要

- 研究一类神经 SDE，分析相关采样最优控制问题随样本量增长到无穷的极限行为：带 N 个样本的神经 SDE 可链接到带集中控制的 N 粒子系统。
- 分析 N 粒子系统对应的 Hamilton–Jacobi–Bellman 方程，建立对 N 一致的正则性结果——经随机最大值原理与向后随机 Riccati 方程分析获得一致正则性估计。
- 用这些一致正则性结果展示：样本量 N 趋于无穷时目标函数极小值与神经 SDE 最优参数收敛；极限对象可识别为定义在 Borel 概率测度 Wasserstein 空间上的合适函数。
- 进一步获得定量收敛率。

## 正文

论文编号：arXiv:2404.05185v4（更新类型：replace-cross）。以下为摘要全文翻译。

本文研究一类神经 SDE，并研究相关采样最优控制问题随样本量增长到无穷的极限行为。带 N 个样本的神经 SDE 可以与带集中控制的 N 粒子系统联系起来。我们分析 N 粒子系统对应的 Hamilton–Jacobi–Bellman 方程，并建立对 N 一致的正则性结果。一致正则性估计通过随机最大值原理与一个向后随机 Riccati 方程的分析获得。利用这些一致正则性结果，我们展示当样本量 N 趋于无穷时，目标泛函的极小值与神经 SDE 的最优参数收敛。极限对象可以识别为定义在 Borel 概率测度 Wasserstein 空间上的合适函数。此外，还获得定量收敛率。

# 评分量表作为开放式生成的优越信息

> [!info] 来源信息
> - 数据源：arXiv cs.LG RSS
> - 作者：Deepika Bablani、Ajay Gupta、Wanming Chen
> - 发布时间：2026-08-05
> - 原文链接：[打开原文](https://arxiv.org/abs/2608.02948)
> - Vault 原文件：[[信息源/arXiv cs.LG RSS/Rubrics as Privileged Information for Open-Ended Generation.|查看原始文件]]

## 摘要

- 在线策略自蒸馏（OPSD）中单个模型扮演学生与教师两种角色（不同上下文），在数学等可验证领域已显前景——ground-truth 答案形式的硬优越信息（PI）从结构上约束有效延续。
- 把 OPSD 扩展到开放式生成：用评分量表形式的软 PI 引导偏好，但允许许多有效响应。
- 评分量表曾作为强化学习（RL）的标量奖励；表明它们作为蒸馏的稠密 PI 提供实质更丰富的信号，且与直觉相反，该情境下软评分量表 PI 在学生 rollout 上提供比硬参考完成 PI 更大、更有效的训练信号。
- 参考完成只是有效响应集合中的一个点，向其蒸馏会过度约束学生；而评分量表规定了有效响应集合共享的偏好结构。
- 在 Qwen 与 Llama 模型家族上展示用评分量表作为开放式生成 PI 的有效性，并表明其优于评分量表即奖励（RaR）RL：用 HealthBench（一个按医生创建的评分量表为开放式健康响应评分的基准，为开放式任务提供稠密 token 级监督）评估，RuPI 相对 RaR RL 最高 +0.10 绝对分数；匹配配方与 KL 方向下，相对参考 PI 在三个模型上 +0.034 到 +0.079 绝对分数。
- 发现可泛化到 RubricHub Science 语料训练与 ResearchQA 评估：软评分量表 PI 优于参考 PI 蒸馏与 RaR RL（66.6% 对 64.2% 与 57.6%）。

## 正文

论文编号：arXiv:2608.02948v1（更新类型：new）。以下为摘要全文翻译。

在线策略自蒸馏（OPSD），即单个模型在不同上下文下同时扮演学生与教师，在数学等可验证领域已显示出前景，其中 ground-truth 答案形式的硬优越信息（PI）从结构上约束有效的延续。我们把 OPSD 扩展到开放式生成，使用评分量表形式的软 PI 引导偏好但允许许多有效响应。评分量表曾作为强化学习（RL）的标量奖励；我们表明它们作为蒸馏的稠密 PI 提供实质更丰富的信号，且与直觉相反，在这种情境下软评分量表 PI 在学生 rollout 上提供比硬参考完成 PI 更大、更有效的训练信号。参考完成只是有效响应集合中的一个点，因此向其蒸馏会过度约束学生，而评分量表规定了有效响应集合共享的偏好结构。我们展示了在 Qwen 与 Llama 模型家族上使用评分量表作为开放式生成 PI 的有效性，并表明它优于评分量表即奖励（RaR）RL。使用 HealthBench——一个按医生创建的评分量表为开放式健康响应评分的基准，为开放式任务提供稠密 token 级监督——RuPI 相对 RaR RL 最多提升 +0.10 绝对分数；在匹配配方与 KL 方向下，跨三个模型相对参考 PI 提升 +0.034 到 +0.079 绝对分数。我们进一步表明这些发现在 RubricHub Science 语料上训练与 ResearchQA 评估时泛化：软评分量表 PI 优于参考 PI 蒸馏与 RaR RL（66.6% 对 64.2% 与 57.6%）。

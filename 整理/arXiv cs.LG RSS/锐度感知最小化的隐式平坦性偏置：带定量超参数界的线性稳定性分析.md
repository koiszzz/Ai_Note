# 锐度感知最小化的隐式平坦性偏置：带定量超参数界的线性稳定性分析

## 摘要

- 锐度感知最小化（SAM）通过寻找损失对局部对抗扰动鲁棒的参数来改善泛化，但其隐式偏向平坦极小值的定量机制仍不清楚；特别是扰动半径 ρ 通常被当作孤立调参变量，尽管它定义了 SAM 测量锐度的邻域。
- 通过线性稳定性分析插值极小值附近的 mini-batch SAM：在局部线性化与梯度噪声对齐假设下，证明每个线性稳定极小值满足 λmax≤³√(bΓ/(2ρη²))，其中 λmax 是最大 Hessian 特征值，b 是批大小，η 是学习率，Γ 界定了梯度范数。
- 该界定量刻画 SAM 的隐式平坦性偏置：保持其他量固定时，更小的批大小、更大的学习率或更大的半径把线性稳定 SAM 限制在更平坦的极小值。
- 它还暴露一个必要权衡：ρ 应足够大以促进平坦性，又要保持足够局部以保留近似与稳定训练。
- 在 CIFAR-100 上对 900 个 ResNet-18 与 VGG-19 模型的受控研究中验证该预测：增大 ρ 与更小的最大 Hessian 特征值一致关联，跨批大小与学习率设置。
- 最后在 Taylor-Locality Controlled SAM（TLC-SAM）中实例化分析：用观测 Taylor 近似误差调整 ρ，进一步相对固定半径 SAM 降低顶部 Hessian 特征值；结果为分析与设计 SAM 变体提供定量超参数界与稳定性—局部性视角。

锐度感知最小化（SAM）通过寻找损失对局部对抗扰动鲁棒的参数来改善泛化，但支撑其隐式偏向平坦极小值的定量机制仍不清楚。特别是，扰动半径 ρ 通常被当作孤立的调参变量，尽管它定义了 SAM 测量锐度的邻域。我们通过线性稳定性分析插值极小值附近的 mini-batch SAM。在局部线性化与梯度噪声对齐假设下，我们证明每个线性稳定极小值都满足 λmax ≤ ³√(bΓ/(2ρη²))，其中 λmax 是最大 Hessian 特征值，b 是批大小，η 是学习率，Γ 界定梯度范数。该界定量刻画了 SAM 的隐式平坦性偏置：保持其他量固定时，更小的批大小、更大的学习率或更大的半径会把线性稳定的 SAM 限制在更平坦的极小值。它还暴露了一个必要的权衡：ρ 应足够大以促进平坦性，又要保持足够局部以保留近似与稳定训练。我们在 CIFAR-100 上对 900 个 ResNet-18 与 VGG-19 模型的受控研究中验证了这一预测：增大 ρ 与更小的最大 Hessian 特征值一致关联，跨批大小与学习率设置。最后，我们在 Taylor-Locality Controlled SAM（TLC-SAM）中实例化该分析，它用观测到的 Taylor 近似误差调整 ρ，并进一步相对固定半径 SAM 降低顶部 Hessian 特征值。我们的结果为分析与设计 SAM 变体提供了定量超参数界与稳定性—局部性视角。

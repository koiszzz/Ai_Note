## 正文

大家好，

Fable 回归以来我用了不少（但没用太久……），而且我几乎没用它做任何构建工作。我喜欢 Anthropic 的模型主要因为它们的思考能力——足智多谋、有创造力，能把一些我经常说不清道不明的东西联系起来。

所以过去一周，Fable 有点像我的治疗师/思考伙伴。但这次感觉有点不一样。可能是我自己的感觉，但它在言谈或思考方式上向我展示了一堆 Opus 式的特质。而且不是因为我提示词被路由到了 Opus（我查过）。

我很期待 GPT 5.6 发布，我觉得就在这周，想看看他们是否终于做出了我追求的那种创造力/思考感觉。Codex 在产品质量上明显比 Claude Code（或 Cowork）好。而且它超快。

照例，我在用方钉填圆孔——一个带编码大脑的编码智能体，用来做创意思考和头脑风暴。不过我确实把 Claude Code 的系统提示词换成了一个更简单的版本，速度快很多，引导也少很多。

我想要一个仍然能构建、但骨子里不那么像开发者的 harness，更像一个能和我认真过招创意思考的对手。我有时会切到普通 Claude 获取不同视角，但那似乎也不够。

我试过技能、提示词和 harness，但似乎都没有得到我想要的。这是我在想做点什么的时候不断思考的问题……我到底想要什么？！如今这个问题经常出现在我脑子里，而我不断说服自己：只有看到了我才知道，所以我得"待在事里"，它才会自己呈现。

但同样，这也可能是 AI 对我的影响——如果任何东西都可以随时生成，那就一直循环生成，直到看到你想要的。不停地转那个轮盘。

看起来健康吗？😅

头条

- 今天是 Fable 在 Claude 订阅中可用的最后一天（至少目前是这样）。从明天起，使用 Fable 需要购买使用额度。所以大家都有攻略要在这最后一天榨干它：用 Fable [找到你的未知](https://claude.com/blog/a-field-guide-to-claude-fable-finding-your-unknowns)——来自 Anthropic 的 Thariq

- 让 Fable 使用[它的判断力](https://simonwillison.net/2026/Jul/3/judgement/)——Simon Willison

这周我基本只用了一个和 Fable 的长对话。它使用记忆、压缩和写文件的方式令人惊叹。我让它大量使用 codex 和 droid 作为子智能体。多到我的 Codex 额度比 Claude Code 额度先用完了。—— Keshav

[Theo 的视频](https://www.youtube.com/watch?v=8GRmLR__OGQ)讲他如何使用 Fable，值得一看，重新想象你应该如何使用新一代 AI 模型，因为记住，GPT-5.6-Sol 很可能本周就会开放使用。你可以期待它带来类似的表现/行为。

- The Information 报道，OpenAI 找到了[把推理成本砍半的方法](https://www.theinformation.com/newsletters/ai-agenda/openai-discovers-new-way-cut-inference-costs-half)，并已在未登录的 ChatGPT 用户上测试。这是否意味着他们最新模型的 API 成本也会降？不确定，但我希望如此。上一次大幅降价大约在一年前，OpenAI 把 o3 的成本降低了 80%。

- [GPT-Realtime-2.1-mini](https://x.com/OpenAIDevs/status/2074255408013955466)——OpenAI API 中的新模型，可以接收视频并输出音频，同时进行推理和工具调用。

- [MIRA 是一个可玩的世界模型](https://mira-wm.com/)，在 1 万小时的类火箭联盟游戏玩法上训练。玩起来就像真的在低画质、操作不流畅地玩这个游戏。

- [Anthropic 的新可解释性研究](https://www.anthropic.com/research/global-workspace)——Claude 使用一个全局工作空间激活许多不出现在输出或思维链中、但影响其工作的概念。研究人员把它比作无意识思维。

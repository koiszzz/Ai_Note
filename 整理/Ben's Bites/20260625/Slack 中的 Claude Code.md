## 正文

大家好，

这里是 Keshav。

大约一周前，我在用 Codex 做一个应用时，看到它用 Image Gen 技能自动生成图片。它把图片当作真正的资源用在了 UI 里。

从那以后，每次构建网页 UI，我都会明确要求它创建图片。效果明显更好：页面看起来不那么寡淡了，而且因为 Claude Code 不能生成图片，输出感觉和常见的 AI 生成 UI 不一样。

试试看吧。

头条

- [Claude Tag](https://x.com/claudeai/status/2069468693017268244) 让你可以在 Slack 中提及一个共享的 Claude Code 实例，像智能体一样在你的团队中协作。把它标记进工作，让它从 Slack 中保持上下文，你在做别的事情时把任务委托给它。

- [Gemini 3.5 Flash 现在具备计算机使用能力](https://x.com/patloeber/status/2069874197086523673)。它可以控制浏览器、移动和桌面环境，谷歌还有一个 [GitHub 仓库](https://github.com/google-gemini/computer-use-preview)，可以在本地或通过 Browserbase 试用。

- [来自 Figma Config 的新品](https://www.figma.com/blog/config-2026-recap/)——把设计图层变成代码、用于动效设计的新工具 Figma Motion、生成可编辑着色器、为插件做 vibe coding、Figma Agent 的第三方连接等等。

- [Notion 的新开发者平台](https://www.notion.com/blog/introducing-developer-platform) 将支持运行基于代码的工作流，并能集成 Claude Code、Cursor、Codex 等外部智能体，让它们基于共享文档和任务看板工作。

- [OpenAI 造出了第一颗 AI 芯片](https://openai.com/index/openai-broadcom-jalapeno-inference-chip/) Jalapeño，与 Broadcom 合作。它面向 ChatGPT、Codex、API 和未来智能体产品背后的 LLM 工作负载。

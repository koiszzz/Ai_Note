头条

- [Codex Record & Replay](https://x.com/OpenAIDevs/status/2067681320281723113)——向 Codex 展示一次重复性工作流，比如填写报销单或提交请假，它就会把演示变成一个可检查、可编辑、可复用的技能。

- [Claude Code 现在有 Artifacts 了](https://claude.com/blog/artifacts-in-claude-code)——带一些功能的 HTML 页面，可以分享给别人（比如 PR 走查或实时项目仪表盘）。Team 和 Enterprise 套餐开放测试版。

- OpenAI 正在扩展其网络安全计划 [Daybreak](https://openai.com/index/daybreak-securing-the-world/)，推出新版本的 GPT-5.5-Cyber（仅限受信任合作伙伴），它能复现比 Mythos 更多的 bug；还有 [Patch the Planet](https://openai.com/index/patch-the-planet/)，一项推动维护者更快修复易受攻击的开源软件的行动。

- [Sakana AI 发布了 Fugu](https://sakana.ai/fugu/)——一个为困难任务挑选并协调多个模型的 API。Fugu Ultra 宣称在 SWE-bench Pro 上 73.7、TerminalBench 2.1 上 82.1，大致是 Fable 级别，但真实使用中你会感到差距。

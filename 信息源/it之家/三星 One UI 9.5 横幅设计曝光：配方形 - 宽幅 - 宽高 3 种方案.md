# 三星 One UI 9.5 横幅设计曝光：配方形 / 宽幅 / 宽高 3 种方案

> 数据源：it之家
> RSS：[打开源文件](https://www.ithome.com/rss/)

> 发布时间：Wed, 05 Aug 2026 02:35:50 GMT　|　原文：[打开链接](https://www.ithome.com/0/985/845.htm)

------

<p data-vmark="1127">IT之家 8 月 5 日消息，科技媒体 sammyguru 昨日（8 月 4 日）发布博文，报道称伴随着 One UI 9 的开发工作接近尾声，<strong>三星的研发重心开始转向 One UI 9.5 系统。</strong></p><p data-vmark="b032">消息源在博文中分享了一张 One UI 9.5 的横幅设计图片，称三星设计了 3 种尺寸：</p><ul class="medium-size list-paddingleft-2"><li><p data-vmark="b18f">方形（square）：主要适用于常规手机屏幕</p></li><li><p data-vmark="a755">宽幅（wide）：适用于 Galaxy Z Fold8 阔折叠手机以及平板电脑</p></li><li><p data-vmark="cb4c">宽高（wide tall）：适用于 Galaxy Tab S11 Ultra 等更大屏幕平板电脑。</p></li></ul><p data-vmark="b807">图案使用青绿色、蓝色和亮粉色 3 种主题色。色彩沿着 3 个图形的边缘分布，3 个图形的圆角半径依次增大。</p><p data-vmark="6f4d" style="text-align: center;"><img src="https://img.ithome.com/newsuploadfiles/2026/8/c51fdce8-ba37-4a3b-ade9-9cfb79aa0e62.png" w="1440" h="405" data-weibo="0" data-vmark="3cca" class="no-alt-img"></p><p data-vmark="f517" style="text-align: center;"><img src="https://img.ithome.com/newsuploadfiles/2026/8/05e40173-94ec-4356-bca8-2a8557ebe2f3.png" w="1440" h="720" data-weibo="1" data-vmark="b7ba" class="no-alt-img"></p><p data-vmark="adf5" style="text-align: center;"><img src="https://img.ithome.com/newsuploadfiles/2026/8/205db999-47f3-44d9-8a15-bc4ddbf37914.png" w="1080" h="1080" data-weibo="2" data-vmark="2bfb" class="no-alt-img"></p><p data-vmark="2229">对于颜色与图形的含义，原文仅作推测。报道称，青绿色和蓝色可能与三星现有的 Galaxy AI（盖乐世人工智能）功能相关；亮粉色的含义则不明确。</p><p data-vmark="f6e3">IT之家查询公开资料，适用于三星 Galaxy S27 Ultra 旗舰手机的 One UI 9.5 固件已经曝光:</p><p data-vmark="a1e7" style="text-align: center;"><img src="https://img.ithome.com/newsuploadfiles/2026/8/727c8800-4c1e-4fd1-9d40-d58150728347.png" w="898" h="1332" data-snap-from="%7B%22from%22%3A%22x%22%2C%22url%22%3A%22https%3A%2F%2Fx.com%2Ffahadalijaved%2Fstatus%2F2083803820761510369%22%2C%22link%22%3A%22https%3A%2F%2Fx.com%2Ffahadalijaved%2Fstatus%2F2083803820761510369%22%7D" data-weibo="3" data-mpos="2,0" data-vmark="6be6" class="no-alt-img"></p>

# Netflix 旗下 FIFA 官方世界杯游戏开发商裁掉 85% 员工，消息称“全员解散”

> 数据源：it之家
> RSS：[打开源文件](https://www.ithome.com/rss/)

> 发布时间：Wed, 05 Aug 2026 12:50:53 GMT　|　原文：[打开链接](https://www.ithome.com/0/986/226.htm)

------

<p data-vmark="ff20">IT之家 8 月 5 日消息，据外媒 VGC 今天（5 日）晚间报道，负责开发 Netflix 足球游戏《FIFA 世界杯：首发版》的 Refactor Games 被曝遭遇大规模裁员，绝大多数员工已经离职，工作室甚至<strong>可能全员解散</strong>。晚些时候，Refactor Games 创始人内森 · 伯巴透露，工作室已经<strong>裁掉 85% 的员工</strong>。</p><p data-vmark="37b1">据IT之家了解，Refactor Games 开发的《FIFA 世界杯：首发版》于 6 月 11 日上线。游戏仅面向 Netflix 订阅用户提供，玩家可以直接在电视上串流游玩，<strong>并把手机当作控制器</strong>。</p><p data-vmark="9961">然而，《FIFA 世界杯：首发版》上线后<strong>口碑惨淡</strong>，还被质疑为了赶上现实中的 FIFA 世界杯揭幕战而仓促完工。</p><p data-vmark="dd56" style="text-align: center;"><img src="https://img.ithome.com/newsuploadfiles/2026/8/1506863e-b37d-47f4-891e-153b841bbfe0.png" w="1440" h="810" id="1785933884297_1" data-weibo="0" data-vmark="1bac" class="no-alt-img"></p><p data-vmark="0580">另外据 Game Developer 报道，多名 Refactor Games 开发人员近日在领英发文，证实自己<strong>与团队其他成员一同遭到裁员</strong>。</p><p data-vmark="e25d">游戏艺术总监巴克利 · 尚特尔写道：“看来我又得开始找工作了。我们刚为 Netflix 推出 FIFA 世界杯游戏，Delphi 便直接叫停了 Refactor Games。<strong>整个工作室今天都被裁掉了</strong>。谁要是想招人的话，我可以帮忙联系一批非常出色的同行。”</p><p data-vmark="8258">产品设计师兼 UI 美术师维克托 · 德尔卡斯蒂略称，游戏上线后，<strong>工作室失去了资金支持，最终被迫关闭</strong>。“作为 UI 美术师，Refactor Games 开发团队是我合作过最优秀的团队，没有之一。每个人都才华出众，而且待人友善，两种品质同时具备并不常见。我们为 Netflix 做完游戏后，工作室母公司便撤回了资金，包括我在内的整个团队随后就被裁了。”</p><p data-vmark="a9d8">美术师约瑟夫 · 奇维塔特写道：“游戏登陆 Netflix 几个月后，Refactor Games <strong>整个工作室都被裁掉了</strong>。由于下一项目的资金被取消，包括我在内的各部门许多优秀员工都失去了工作。”</p><p data-vmark="685c">游戏上线一周前，Netflix 曾在 6 月初发布新闻稿称：“‘首发版’只是我们的‘开球’，<strong>游戏今后还会不断发展</strong>。”随着开发团队遭到解散，Netflix 是否已经放弃持续更新和完善游戏的计划，目前仍不得而知。</p>

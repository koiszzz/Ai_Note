# 微软酝酿 Win11 26H2 更新，版本号将升至 Build 26340.x

> 数据源：it之家
> RSS：[打开源文件](https://www.ithome.com/rss/)

> 发布时间：Wed, 05 Aug 2026 02:19:19 GMT　|　原文：[打开链接](https://www.ithome.com/0/985/817.htm)

------

<p data-vmark="4012">IT之家 8 月 5 日消息，科技媒体 The WinCentral 昨日（8 月 4 日）发布博文，报道称微软计划面向 Experimental 通道 Windows Insider 项目成员，<strong>推送 Windows 11 26H2 Build <span class="link-text-start-with-http">26340.xxxx</span> 预览版。</strong></p><p data-vmark="cf66">IT之家注：基于微软目前的发行策略，Windows 11 的三大版本分支如下：</p><ul class="medium-size list-paddingleft-2"><li><p data-vmark="8725">Windows 11 24H2：源码分支属于鍺（Germanium），Build 版本号前缀为 26100</p></li><li><p data-vmark="5541">Windows 11 25H2：源码分支属于鍺（Germanium），Build 版本号前缀为 26200</p></li><li><p data-vmark="5828">Windows 11 26H2：源码分支属于鍺（Germanium），Build 版本号前缀为 26300</p></li></ul><p data-vmark="409e">不过<a href="https://www.ithome.com/0/984/402.htm" target="_blank">该媒体挖掘 Windows 11 最新预览版 Build 26300.9032</a>，在 <span class="link-text-start-with-http">C:\Windows\servicing\Packages</span> 路径下，发现了 Ge-26340 的引用字符串。</p><p style="text-align: center;" data-vmark="8754"><img src="https://img.ithome.com/newsuploadfiles/2026/8/ecb75d14-7447-4c46-994f-8fb55d350a1f.png?x-bce-process=image/format,f_auto" w="696" h="570" data-weibo="0" data-vmark="f51b" class="no-alt-img"></p><p data-vmark="7a3a">对此该媒体认为，<a href="https://www.ithome.com/0/968/776.htm" target="_blank">微软后续可能通过启用包（Enablement Package）KB5122776 方式推送</a>，将目前 Windows 11 26H2 预览版升级到 Build 26340 前缀中。</p><p style="text-align: center;" data-vmark="d0ed"><img src="https://img.ithome.com/newsuploadfiles/2026/8/3828699c-3d80-460f-a677-fbe05ba6a063.png?x-bce-process=image/format,f_auto" w="696" h="390" data-weibo="1" data-vmark="d4bb" class="no-alt-img"></p>

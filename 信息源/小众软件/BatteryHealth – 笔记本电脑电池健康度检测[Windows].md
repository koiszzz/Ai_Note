BatteryHealth 是一个极简的 Windows 电池健康查看器。只有 37.8 KB 大小，即用即抛。@[Appinn](https://www.appinn.com/batteryhealth/)

![图片](https://static3cdn.appinn.com/images/2026/08/Copy-of-appinn-homework-2026-08-07T144314.006.jpg)

打开 BatteryHealth 后立即读取 Windows Battery Class Driver 信息，显示健康度：

![图片](https://static3cdn.appinn.com/images/2026/08/屏幕截图-2026-08-06-162719.avif)

![图片](https://static3cdn.appinn.com/images/2026/08/640-2.avif)

还可以查看到：

- 电池名称

- 制造商

- 设计容量

- 当前满容容量

- 损耗

- 循环次数当前电量

等信息。

适用于 Windows 10 / 11，使用系统自带的 .NET Framework 4.8。

主打一个方便，即下即用即抛。

注意，该工具获得的电池信息，与微软官方提供的方式《[在 Windows 中关爱电池](https://support.microsoft.com/zh-cn/windows/experience/power-battery/caring-for-your-battery-in-windows)》是相同的，即：

在命令提示符下，键入 powercfg /batteryreport，然后按 Enter。电池报告将是存储在电脑上的文件夹中的 HTML 文件。 文件位置将显示在命令提示符窗口中。

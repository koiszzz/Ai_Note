## OneDrive 照片 / OneDrive Photos 是什么？

青小蛙从 [windowslatest](https://www.windowslatest.com/2026/08/09/microsoft-confirms-it-accidentally-installed-new-onedrive-app-on-windows-11-pcs-and-theres-no-easy-way-to-remove-it-yet/) 看到说：微软说他们不小心在 Windows 11 中更广泛地发布了由人工智能驱动的 OneDrive 照片应用，这解释了为什么企业 PC（该应用甚至无法运行）现在不得不面对这个问题。

大概从这个月初开始，OneDrive 照片 就开始悄悄出现在大家的 Windows 11 中了，推广到了「几乎所有安装 OneDrive 同步客户端的用户」，如果你也在使用 OneDrive，快看看电脑里有没有

![图片](https://s.w.org/images/core/emoji/17.0.2/72x72/1f602.png)

![图片](https://static3cdn.appinn.com/images/2026/08/屏幕截图-2026-08-09-162327.avif)

OneDrive 照片会同时显示本地图片与云端图片，比如上图，就是QQ安装文件夹中的表情，也被显示了出来。

这是一个 WebView2 应用，在离线状态下（已登录）占用了 138MB 内存：

![图片](https://static3cdn.appinn.com/images/2026/08/屏幕截图-2026-08-09-162759.avif)

设计还算不错，与其他 Windows 11 应用那种用起来卡卡的感觉不太一样，青小蛙觉得，还真不错。

尤其是从不同文件夹进入后显示图片的速度。

目前并不清楚青小蛙这个离线是什么情况，因为左下角是可以看到登录成功的，点击后也能显示账号名称，但就是提示离线。

并且精彩瞬间、人物、相册都不可用。

未来的 AI Agent 很可能会占据互联网上的大部分区域，包括交易。

### AI Agent 购买服务

未来你可能只需要告诉 AI：“帮我把这段视频翻译成日语，并生成配音。”

AI Agent 就可以自己去寻找合适的 API，然后完成支付，最终实现翻译并配音。

现如今你可能还需要给 AI Agent 配置翻译 API，人工充值，然后才可以完成这项功能。

### 网站为 AI 提供服务

上面的例子反过来，你只需要提供一个接口，AI 就可以支付并使用该接口。

那么他们之间的自动化交易就缺少一个渠道，无论是 Paypal、Stripe，传统信用卡，还是支付宝、微信，虽然部分已经支持 API，但主要用户还是人类，并没有办法解决“一个AI Agent 如何证明自己是谁，以及它能花多少钱”这个问题。

于是，可编程的 Cloudflare Wallet 就这样来了。

## 认领 Cloudflare Wallet

目前的 Cloudflare Wallet 还处于认领阶段，未提供服务。但是你可以先注册一个 @appinn 这样的用户名，以代表未来的你（AI Agent）。

抢注地址：[https://cloudflare.pay/](https://cloudflare.pay/)

一个 Cloudflare 账号只能注册一个钱包用户名。比如青小蛙想要注册 @qingwa 就失败了

## Cloudflare Wallet 有什么用

Cloudflare 钱包可以存储稳定币（stablecoins）、购买服务，以及接收资金。还能创建多个虚拟钱包，以便用来在不同的地方购买 API、MCP 等工具，还能设置限额、允许列表和最大交易额。

用户名的作用在于与商家互动时拥有稳定的身份。

配合此前 Cloudflare 推出的 Monetization Gateway（变现网关），AI Agent 们就可以在上面实现自动化交易了。

Hey folks,

I’m making progress on my agents manual! I think I finally figured out how I want the thing to look and feel.

I’ve built and rebuilt this damn thing so many times in this process, which is actually part of the process. I am a lazy workaholic (h/t Rick Rubin) - I have to spend time in the work, even if it feels like it’s not going anywhere, until ‘suddenly’ things click.

Whilst in the process, you find yourself wanting tools to exist to make things easier for yourself—that’s a huge part of why learning agents and how to steer them is so good.

You can build tools to enable you to build things.

I spun up this tool before bed last night where I can comment/delete on copy whilst I’m building, which I copy as one big block as agent feedback.

Headlines

- [Codex has two new additions: Plugins and Sites](https://openai.com/index/codex-for-every-role-tool-workflow/). Plugins are pre-built collections of skills, connectors to relevant apps (like Figma for designers) and instructions tuned for specific roles like data analysis and product design. [Sites](https://x.com/_simonsmith/status/2062168863400235023) lets users create a shareable website/app with a database, file storage, env vars, access controls, and more. Initially only available to business and enterprise users.

- A bunch of new open models released recently -[Gemma 4 12B](https://blog.google/innovation-and-ai/technology/developers-tools/introducing-gemma-4-12b/) - Multimodal (i.e. accepts images and audio as input) and performs nearly as well as the two-month-old 26B variant.

- [Ideogram 4.0](https://ideogram.ai/blog/ideogram-4.0/) - 9.3B model for image generation. Trained on JSON prompts for control over the layout, colours and text for each element on the image. Also check [Reve 2.0](https://blog.reve.com/posts/the-layout-bet/) for the focus on layout of elements in an image (but it’s closed-source).

- [Miso One](https://x.com/AodenTeoMT/status/2062204362102100295) - 8B text-to-speech model claiming expressive speech with 110ms latency.

- Also, just like Cursor’s Composer, more companies are trying out fine-tuning big open-weights models for their domain-specific work. Latest entry → [Harvey](https://x.com/harvey/status/2062218656420167785) got a Kimi 2.6 agent to beat Opus 4.7 on its legal benchmark at ~11x lower cost.

- [Microsoft Scout](https://www.microsoft.com/en-us/microsoft-365/blog/2026/06/02/introducing-microsoft-scout-your-always-on-personal-agent/) is an always-on Microsoft 365 agent built on OpenClaw (reminder: openclaw is open-source). Different approach from what Google is doing with Gemini Spark.

- [Ramp Stack](https://ramp.com/stack) - An accounting assistant that helps with month-end close work: reconciling accounts, preparing schedules/accruals and more with reviewable sources. They also published a nice blog post explaining their [efforts to benchmark Stack](https://builders.ramp.com/post/stack-benchmarking) against other frontier models.

- Financial fraud is evolving fast. It’s time to fight back—with AI. My feed

- [Smallest AI](https://smallest.ai/?utm_source=benbites&utm_medium=newsletter&utm_campaign=tool) lets you deploy voice agents at scale, powered by realtime STT & TTS and production-ready telephony infrastructure.*

- [Bloom](https://www.ycombinator.com/launches/Qd6-bloom-the-brand-layer-for-agents) turns your brand assets, site, decks, Figma and socials into a callable system that agents can use via API/MCP to generate on-brand assets.

- Windsurf is now [Devin Desktop](https://x.com/cognition/status/2061889596703551926). It manages fleets of local and cloud agents from the editor. Nous also released a desktop app for its CLI agent [Hermes](https://hermes-agent.nousresearch.com/desktop).

- [Hallmark v1.1](https://x.com/nutlope/status/2062226108154618268) - open-source design skill for coding agents.

- 40% of Cursor's internal PRs now coming from cloud agents. More deets in their post about [lessons from building cloud agents](https://cursor.com/blog/cloud-agent-lessons).

- [Factory Router](https://factory.ai/news/factory-router) routes each agent session to the right model and keeps near-frontier performance at 20-25% lower cost in its benchmarks.

- The next frontier of [visual AI is code](https://www.a16z.news/p/the-next-frontier-of-visual-ai-is).

- [ViBench](https://x.com/amasad/status/2062226152790675805) - benchmark from Replit with tasks focused on end-to-end app creation; Opus 4.8 beats GPT-5.5 on price/performance for vibe coding.

- [Skills for macOS](https://github.com/robzilla1738/skillz-macos) - app for browsing and editing local skills, MCP configs and plugins.

- [Ollie](https://x.com/blennon_/status/2061868938443550842) - AI assistant for parents to manage the chores to free up time for family.

- [Television](https://x.com/telepathinc/status/2061900965251604956) - visual workspace for personal agents. Notion-like kanban board vibes but with each tile attached to an agent.

- [Building software is learning](https://registerspill.thorstenball.com/p/building-software-is-learning) - it’s an iterative process that will run into questions and obstacles. You should want that to happen as fast as possible.

- A functional taxonomy of [world models](https://x.com/drfeifei/status/2062247238143996275).

- Collection of [agentic engineering hacks](https://x.com/mvanhorn/article/2061877533885473181) for June 2026.

- [Modern Engineering Values](https://cpojer.net/posts/modern-engineering-values) - a workflow and engineering values built after shipping several mostly or fully AI-written projects.
